player.rank / rankTracker.registeredRank → rank re-test
player.class / classRank / job / title / push player.titles[]
stats.strength/agility/vitality/intelligence/perception + stats.availablePoints (decrement when allocating)
stats.qi / qiMax / will / willMax / cycles / enlightenment / windTax / corruption / agilityGrade → QI/WILL bars + Twin Gale
